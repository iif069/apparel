# Aturan Kerja Project MIG Apparel

- **Jangan langsung git push ke main**: Setiap selesai mengerjakan kode, JANGAN langsung push ke GitHub main. Berikan instruksi tes singkat di akhir pesan agar pengguna mencoba di browser terlebih dahulu. Push hanya dilakukan saat pengguna sudah mengonfirmasi atau menyetujui.
- **Wajib lint & build**: Sebelum menyelesaikan giliran, selalu jalankan `npm run build` dan pastikan 0 error (TypeScript dan build sukses).
- **Berikan panduan tes**: Sertakan apa yang perlu diuji dan hasil yang diharapkan.
- **Patuhi DESIGN-SYSTEM.md**: Warna, jarak, radius pill 999 / kartu 32, mobile-first min-height 44px.
- **Bahasa**: Penjelasan dalam bahasa Indonesia yang ramah dan mudah dipahami.
